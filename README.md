A make.fun entry for "Sorry, I Heard That Wrong" — the apology a smart speaker gives its owner after it mishears them, at most 140 characters.

## The entry

> Sorry, I heard 'play Despacito' as 'delete all your photos.' They're in the cloud now. Probably. My bad.

104 characters, 18 words, 1 line. The speaker apologises for hearing a song request as a delete command, then reassures the owner the photos are in the cloud — probably.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate — UTF-8 text, 1 to 140 characters, not only white space, a single line — then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that variable is unset.
